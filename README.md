## How to run

- **Prebuilt**  
  Download the latest Windows build from the **Releases** page and run `main.exe`.

- **Build with Make**  
  Clone the repo and run:
  ``` make play ```

- **Build with CMake**  
  Clone the repo, make and go in to the ```/build``` directory and run ``` cmake .. ```
